# ConvertVideo 
Proyecto de práctica
Convertidor de videos de Youtube para descargar en full cálidad y en formato mp3 o mp4

## Uso 
Coloca el link en el input,  selecciona el formato en el que quiere descargar el video, yespere a que se descargue 

## Avisos!!
La página tarda en cargar la primera vez que se ingresa. (Trabajando en eso)
